# RF Amplifier ADL5602
RF Amplifier based on Analog Devices ADL5602
with optional LDO power supply.

**Specification**
- 50MHz-4GHz
- 20dB Gain
- 5VDC direct supply
- Alternative 1.6V to 6V power supply
